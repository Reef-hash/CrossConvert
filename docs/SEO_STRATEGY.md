# SEO Strategy

## SEO Model
CrossConvert is designed for programmatic SEO. The same catalog that powers routing also powers titles, descriptions, keywords, canonical URLs, and sitemap generation.

## Current Foundations
- home page metadata
- category page metadata
- tool page metadata
- route registry for sitemap generation
- structured data injection support

## Page Types
- home page for broad category intent
- tools index for discovery intent
- category pages for topical clusters
- tool pages for high-intent long-tail keywords

## Internal Linking Strategy
- homepage links to category pages and featured tools
- category pages link to all category tools
- tool pages link to recommended and related tools
- future guides will link back into tool clusters

## Programmatic SEO Strategy
- every tool slug maps to a unique title and description
- every category owns a descriptive landing page
- sitemap is generated from the route registry rather than manually maintained
- schema can be expanded per tool type without changing route code

## Future Content Layers
- comparison pages such as WEBP vs PNG, JPG vs WEBP, AVIF vs PNG
- best-practice guides for compression, quality, OCR, captions, and API usage
- industry landing pages for designers, developers, operations, and media teams
